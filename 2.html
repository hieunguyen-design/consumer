Connect your Facebook account

OAuth runs in your browser. Tokens stay in sessionStorage and are never sent anywhere but graph.facebook.com.

One-time app setup

  1. Create an app at developers.facebook.com/apps → type Consumer.
  2. Add the product Facebook Login → Web, set Site URL to this page's origin.
  3. In Facebook Login → Settings, add this origin to Allowed Domains for the JavaScript SDK.
  4. Paste the App ID below. Page must be served over https:// or http://localhost.
Advanced: use an access token directly

Generate one in Graph API Explorer to test before App Review. Stored in sessionStorage only.

API limits: /me/friends returns only friends who also use this app (total count is still real). There is no endpoint for the people/pages you follow — use the data export tab for a complete list.

The only complete source for your following list

  1. Facebook → Settings & privacy → Accounts Center → Your information and permissions.
  2. Download your information → Some of your information → check Followers and following + Friends.
  3. Format JSON → download → select following.json, followers.json, friends.json below.

Files are parsed locally with FileReader; nothing is uploaded. Accounts present in followers/friends files are auto-tagged Mutual.
